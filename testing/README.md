# 測試文件（Testing）

本專案包含手動測試相關文件，主要針對拉麵點餐系統進行功能驗證與測試。

## 測試內容

本次測試涵蓋以下項目：

- 正常流程測試（Happy Path）
- 必填欄位驗證（Empty Input）
- 資料型別驗證（Invalid Input）
- 邊界值測試（Boundary Value）
- 使用者操作測試（重複送出）

## 測試方式

- 使用 Test Case 設計測試情境
- 透過手動測試驗證系統功能
- 比對預期結果與實際結果

## 測試成果

- 發現系統在「重複送出」情境下，會產生多筆訂單
- 已記錄於 Bug Report 文件中

## 檔案說明

- ramen_testcase.xlsx：測試案例與測試結果
- ramen_bugreport.xlsx：測試過程中發現的問題紀錄
